# npm 显式父工作区归属

Unix `cve typescript PROJECT --workspace WORKSPACE` 将原生执行目录保持为 PROJECT，持久观察及稳定任务归入已初始化的 WORKSPACE。未指定时仍使用项目自身，不自动搜索父目录。默认预算读取所选工作区；命令行及登记环境的优先级保持原契约。

工作区必须是规范化物理绝对目录，项目必须位于其组件边界之内。兄弟目录 a/ab 不视为包含，工作区符号链接别名在原生执行前拒绝。next 的 npm 复检参数保留 --workspace，以免下轮落入子项目工作台。

`npm_workspace_scope_cli` 通过受控普通二进制测试验证两子项目创建两张父任务、重复扫描不重复创建、无子任务目录、父预算优于子配置、next 保留归属，以及越界/链接拒绝时工具哨兵未执行。本验收不是可信漏洞库或真实 npm 原生执行证明。
