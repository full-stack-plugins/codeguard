# 限定任务共享提交边界

日期：2026-10-05。对应OpenSpec 9.10 / 14.11，父任务未完成。

## 变化

现有Zig、Erlang、Swift、Kotlin服务分离原生复检与`commit_resolution`。语言入口仍核对签名、任务、原始/当前源码、原工具及覆盖；提交层复用相同父链算法和文件格式，没有新增CLI批准入口，也没有从项目决策文件读取信任。

提交前增加域证据与脱敏原生证据的一致性核对：稳定身份、首次报告、原/当前源码、工具、适配器、grammar或批准策略、策略修订、结果及原生对照摘要。原生首次来源以批准策略摘要作规则包身份，不伪造grammar。共同提交还核对Core解决条件，不单凭policy_verified字段关闭。相同证据幂等、不同关闭须协调、策略变化须核对、已有关闭后仍存在则重开；收据及证据版本不变，不授予项目门禁。

## TDD与回归

新增跨表示反例先失败：身份被换时旧提取逻辑进入历史读取，返回task_lifecycle_directory_invalid，而非预期绑定拒绝。加校验后该单元通过，十三类拼接被拒绝于历史读取前。第二个RED反例发现未知证据版本仍进入历史读取；固定封闭字段与0.1–0.5版本后重跑通过。完整匹配的证据仍进入历史读取，不以无条件拒绝通过测试。

提取前基线：五组服务测试31通过、5忽略，涵盖Zig两类来源和Erlang/Swift/Kotlin。忽略的实际原生工具测试不计通过。本轮服务回归使用独立签名及工具夹具，不作为实际宿主密钥来源或真实工具验收。

拆分后五组回归同样31通过、5忽略，关闭、幂等、复发、租约、原生反证、过期/撤销签名及分叉历史断言均保持。未知版本和封闭字段补强后，另行重跑共同提交单元与旧Zig完整关闭/重检/重开链路，均通过；后者52.58秒。默认与wasm-precheck的CLI全部targets严格Clippy均通过，OpenSpec严格校验及diff检查通过。

## 剩余范围

Python需要专用签名策略（明确lint目标与配置）、两类首次证据和双输入原生复检，并对新证据版本和普通复发接线；本轮共享提交边界不是Python关闭能力。现有各语言完整项目覆盖和实际受保护宿主验收仍缺。未更新npm、插件默认锁或grammar资格；Erlang既有草稿保持原字节并排除提交。
