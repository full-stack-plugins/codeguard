# ESLint 有效配置查询中断验收

公开 task verify 在扫描之后查询有效配置时，也必须保留统一取消和截止时间。受控 CLI 回放使用原查询参数启动真实进程组，等待查询启动标记后向 CLI 发送 SIGINT；查询子孙计划延迟写文件，退出后等待并确认没有逃逸写入。

该反例先 RED：运行时已回收查询进程，但观察原因变成 eslint_effective_execution_incomplete，原扫描 finding 导致复检分类 still_present，且保存了正常事件。现查询前后优先核对取消/期限，保留 request_cancelled；复检封装和分类保留中断，公共任务验证取消后不进入正常观察持久化，仍完成租约释放。再次调用无上下文复检能保存局部未完成事件，证明没有遗留占用。原问题仍保留，取消不充当源码修复或有效覆盖。

本轮目标用例 3.84 秒通过；包括该用例、规则解析3、公开ESLint6、租约16、任务复检10在内的36项普通回归通过。目标Clippy -D warnings及fmt通过。这是受控进程/公开CLI取消验收，脚本不是原生ESLint，不声称通过原生工具行为、Windows Job Object或完整历史/硬I/O预算。中断历史协议、跨宿主取消、正式关闭/重开与完整项目覆盖仍属未完成任务。
