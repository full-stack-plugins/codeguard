# npm 输入绑定运行服务（2026-09-27）

Rust `run_npm_audit_probe` 将明确Node/npm、清单、v3锁、用户/全局npmrc及存在的项目npmrc绑定到精确预期SHA集合，拒绝缺失/额外/别名输入。版本查询沿用审计的显式配置、缓存与源参数。版本、原生audit、证据落盘、有界stdout解析及锁节点关联使用同一截止时间，取消优先。

输入在版本查询前后、审计后及最终关联后核对；原先不存在的项目npmrc若新增也视为输入变化。变化时不返回可消费parsed或锁节点结论；报告与工具失败不是源码违规。原生stdout通过runtime私有日志留存，不假定npm会写ESLint式独立JSON报告。

一个反例测试遍历稳定、锁改写及npmrc新增三种模式，并分别验证预取消、过期截止、缺输入身份和具体版本错配。缺服务API先失败，私有目录/报告输出方式纠正后通过。六项审计及两项锁关联契约回归通过。真实npm空锁场景接入服务并核对版本及局部一致性，原生两项测试首轮通过（22.29秒）；最终版本参数一致性修改后的两项原生复验通过（21.68秒），Clippy、格式及OpenSpec严格校验通过。

服务仍是局部观察而非正式CVE命令。全部Node/npm模块闭包、祖先配置、环境变量语义、认证、缓存/数据库权威和时效、系统级网络隔离及不可中断文件I/O总预算仍缺，coverage保持not_evaluated；公开入口与稳定修复任务未完成。7.3/7.5不勾选。
