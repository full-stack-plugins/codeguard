# 最终门禁时刻核对白名单期限（4.5/4.8 进行中）

旧领域判定只比较 expires_at 与 observed_at，不能表达检查过程中批准已经到期。DeliveryInput 新增 gate_time_unix，可缺省读取旧输入；应用白名单时必须由可信宿主在最终判定前重新取时钟，满足 0 < observed_at <= gate_time_unix < expires_at。不能把扫描开始时间拷贝为最终时刻。到期右边界不包含，缺时钟、零值或早于取证的时刻均不应用处置，保留原始及活动阻断并返回 Incomplete。

无白名单的普通门禁不因缺此新增时钟字段改变结论。AllowlistDisposition.expires_at 是宿主完成决策、签发及密钥有效期核验后固定的最早到期边界，不能只采用较长的候选文档期限。当前领域类型不自行读取系统时钟，也不认证调用方时间来源；真实宿主仍须提供可信时钟和完整签名/撤销状态。

RED 为接口缺少最终门禁时钟字段，测试编译失败。29 项门禁用例包含 100/150/199 有效、200/250 到期、99 回退、0 和缺值拒绝，以及旧输入缺最终时钟不能重放豁免；会话 8 项、RunReport 14 项、带例外反馈 7 项、SARIF 3 项、签名与签名链各 5 项、批准快照 15 项及 core 回归通过。以上为确定性领域/协议测试，不证明实际宿主时钟或批准来源。

VerifiedApprovalSnapshot 增加私有的 expires_at 及只读方法，其值只能由签名载荷核验后构造。第二次 RED 为读取方法缺失；签名用例核对返回已签上限 200。宿主应以当前签名、当前候选与当前密钥等约束固定最早边界；历史批准仍按其受保护审核时刻核验，不能将历史到期时间缩短为合法替代条目的当前期限。读取方法没有新增授权、签发或交付结论。

本轮只改纯领域期限检查、开发期调用者与已验签元数据，未修改原生进程或适配器；采用上述受影响回归及全目标静态检查，不重复运行未受影响的原生环境验收。最终 Clippy/fmt/OpenSpec 结果另记。真实批准生产与宿主门禁仍未接通，4.5/4.8 不勾选。
