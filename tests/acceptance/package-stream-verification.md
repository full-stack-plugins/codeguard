# 发行包流校验与缓存发布衔接

对应 OpenSpec S05/5.3 的展开前包流契约；实际网络下载和完整安装尚未完成。

runtime read_verified_package 接受读取器、精确大小（1..128 MiB）、非零 SHA-256、共享截止时间/取消标记。逐段读取及增量摘要，超长最多多读一个字节即拒绝，try_reserve 失败返回固定原因。中断重试沿用预算，读取前后及返回前检查取消/期限；短/长流、错误摘要、读取或分配失败不返回成功字节。错误不携带原始传输信息，无展开、执行、来源批准或发布行为。

6 项初始测试因 API 缺失失败；实施及补充后 9 项包流测试与 10 项已有缓存发布测试通过。包流覆盖正确字节、短/长/错摘要、非法输入读取前拒绝、途中取消、固定脱敏传输错误、中断重试、超长仅读声明加一、read 返回后到期拒绝，以及真实临时缓存 raw 字节发布/重验复用。错误包校验失败时缓存保持空；有效包使用同一预算交给原有不覆盖发布 API。缓存发布的 1 项显式原生 Ruff 测试本轮 ignored，没有计入通过。

任意阻塞 Read 不能由此函数强行中断；实际传输层须设置单次连接/读取超时。本轮未实现或验收 HTTPS/TLS/重定向、可信来源、网络下载、归档展开、正式 CLI apply、全平台或宿主端到端；未运行全 workspace。字节相符仅是内容验证，不是安装批准或质量通过，5.3/5.6 不勾选。
