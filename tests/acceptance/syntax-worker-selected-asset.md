# 语法 worker 按需资产校验局部验收

日期：2026-09-29。范围：已固定的 15 份候选 grammar，仍非语言能力或发行验收。

原实现的每次 `__syntax-worker <language>` 都先调用全量 `bundled_grammar_candidates()`，对所有已打包 WASM 和许可证重新计算摘要，再选择一份资产。随着语言数增加，单文件反馈会承担无关语言的校验开销。

现在 worker 通过 `bundled_grammar_candidate(language)` 仅选择固定清单中的目标语言，校验 CodeGraph 许可证、该语言的 WASM 与许可证，以及该语言适用的来源适配关系；Objective-C/Solidity 额外校验依赖包许可证。未知语言拒绝。全量 `grammar status` 仍校验全部资产。测试先因缺少选择接口而编译失败，随后证明 15 份选择结果与全量清单身份及字节长度一致，未知语言拒绝。

调试构建、同一主机上的一次前后观察：Lua worker 从约 2.14 秒到 1.63 秒，C# 从约 3.25 秒到 1.62 秒。此观察包含进程启动和 Rust WASM 解析开销，不能分离摘要计算贡献，也不能当作正式冷/暖启动性能基准。

未完成：32 份资产覆盖、逐语言语料与原生对照、公开原生优先路由、宿主实装及发行验收。候选仍不能代替原生 lint；结果仍为 `incomplete`。
