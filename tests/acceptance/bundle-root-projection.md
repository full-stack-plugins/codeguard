# 显式归档目录到 bundle 根映射

对应 OpenSpec S05/5.3。正式安装未完成。

`project_unpacked_bundle` 接受完整归档、显式包内目录、预期 bundle 树摘要及共享期限/取消信号。先核验完整原树，再按目录边界去掉前缀；空字符串明确表示整棵树，不猜测包顶层目录。选中的空目录保留，其余成员以原路径和完整内容返回，文件内容转移所有权而不复制。`ProjectedBundle` 只读字段与访问器不授予来源或安装批准；消费后落盘必须再次核验。

四项 runtime 契约最初因 API 缺失编译失败，实施后通过：精确目录边界与兄弟目录隔离、空目录与未消费成员保留、整树显式选择、非法/缺失/文件/大小写错误根拒绝、原树外部非法路径拒绝、内容篡改与无效摘要拒绝、取消及预算到期。CLI 第四项完整树契约把投影实际写入临时目录，与既有 `hash_bundle_tree` 精确比较，验证去前缀后的身份与原生目录身份一致。

本轮 projection 4、归档 19、包流 9、缓存 10、完整树 4、制品身份 8、crate 边界 5，共 59 项通过。1 项原生缓存用例 ignored，不计运行。本轮没有启动原生扫描器，未运行全 workspace，也未实测 Windows。
