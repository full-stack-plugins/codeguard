# 发行清单与冻结 bundle 包内容关联

对应 OpenSpec 5.3，正式安装仍未完成。

发行清单 1.1 加入 bundle_archive_root：有 bundle 树摘要时必填，空字符串明确选整树；没有 bundle 或 raw 包不能携带映射。1.0 继续解析/观察，但不能声明该映射或据此猜根。既有 1.0 schema 独立保存，当前 schema 支持两个版本。

inspect_distribution_bundle 只做内容关联：从有界清单原字节解析，绑定同一原工具锁字节和精确工具/平台，核对包的精确大小，再由 runtime 验证包摘要、入口字节及完整归档树，最后按显式根投影并核对锁中 bundle 摘要。返回只读 ProjectedBundle 和未消费成员，不下载、执行工具或写缓存，也不授予清单批准。调用方的摘要来源仍须可信宿主独立核验。

两项清单契约先因 1.1 不支持失败；三项包关联契约先因 API 缺失编译失败。实施后清单 13、包关联 3、安装观察命令回归 23，共 39 项通过。固定 ZIP fixture 包含子树内库/空目录和外部入口、名称相似的兄弟目录。正例精确保留内容；坏大小、错包摘要、缺入口、错根、篡改包、锁字节变化、旧版缺映射、错误工具选择、取消和期限耗尽均拒绝。fixture 为固定日期/普通文件和目录的存储 ZIP，不执行其中内容。

schema 正反例另验证 4 个合法声明与 10 个非法版本/根/字段组合。全 workspace、Windows 及真实下载/原生工具运行尚未验收。正式来源批准、包内根到实际缓存目的目录的映射、目录原子发布、CLI apply/恢复仍未接通，5.3 不勾选。
