# HTTPS 包与完整树关联及临时发布

对应 OpenSpec 5.3；正式安装仍未完成。

新增 download_verified_archive：请求前校验下载与归档同一非零包 SHA-256、zip/tar_gz、规范入口、非零入口/完整树摘要和展开预算。下载继承既有 TLS/重定向/长度/摘要约束；随后原归档入口在同一绝对期限/取消下核对包及入口，再核对完整 bundle-tree-v1 摘要。失败不返回局部树，不写缓存、不授予来源/安装权威。

最初新测试因 API 缺失编译失败；实现后 15 个 HTTPS 目标测试通过，包含原 11 项传输用例和新增 4 项：ZIP/tar.gz 经本地真实 TLS 下载、完整树核验后由独立发布层写私有临时缓存，bin/tool 与空目录实际磁盘内容相符；错误完整摘要拒绝。raw 实际下载及字节缓存发布正确，错误包摘要返回固定失配。下载/归档摘要冲突，以及坏格式、入口、预算、零入口/树摘要和大写摘要均在生产公开入口发送请求前拒绝。测试专属 CA 只用于 cfg(test)，不执行下载的 tool 测试字节。

这是底层串联证据，未将工作区声明升级为发行来源批准。生产下载入口仍要求调用方先独立核验网络/来源授权；tools install 尚未接入此 API，正式 apply、运行时安装、恢复、远端可信发行源与跨平台/宿主验收仍缺。未运行全 workspace，任务不勾选。
