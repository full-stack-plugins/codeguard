# 发行清单与候选锁的精确绑定

对应 OpenSpec S05/5.3 的输入契约基础；完整 tools install 未完成。

新增 distribution-manifest 1.0 schema 与 Rust 解析/绑定 API。清单最大 256 KiB、最多 256 个唯一工具/平台条目；拒绝未知/重复字段、零或非法摘要、凭据/查询/片段/非 HTTPS 地址。包传输上限 128 MiB、展开上限 512 MiB。raw 包摘要与二进制摘要、包大小与展开大小须相等，不含归档入口/bundle；zip/tar_gz 必须声明规范相对入口，禁止回退、空段、绝对路径及控制字符。

绑定重验可变对象，核对原始锁字节摘要及 managed_cache 来源、精确工具/版本/平台/来源引用摘要/二进制/bundle。返回值仅是显式制品子集，不表示完整库存、独立运行时、可信来源、批准、安装或准备通过。固定 http 1.5.0 仅作 URI 解析，未引入 HTTP 客户端或联网行为；CLI 其它 crate 不可依赖它。

11 项契约与 4 项 crate 边界最终状态测试通过（无 ignored）。契约覆盖精确绑定、锁字节变化、对象改写、错误身份、重复 JSON 字段/条目、未知批准、非法地址/入口、raw 交叉字段、两种归档声明及有界输入。JSON Schema 校验本身通过，4 个正例和 16 个反例通过。重复字段、跨字段相等、字节长度和 URI 语法由 Rust 补充验证，schema 不是独立授权依据。all-target Clippy（-D warnings）通过。

尚未接入 CLI 清单参数、独立批准来源、实际下载、归档展开或完整 apply；未运行网络/全平台/宿主端到端与全 workspace 测试，不勾选 5.3/5.6。
