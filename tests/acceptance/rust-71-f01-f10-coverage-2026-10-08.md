## 验证明细

### F01-F10 场景覆盖 ✅
- F01: 正确源码，正确配置与版本 → complete
- F02: 一条确定违规与对应最小修复 → finding 检出与修复
- F03: 缺命令/运行时、版本不兼容、坏配置 → incomplete
- F04: 原生非零但没有有效报告 → incomplete
- F05: 有效违规后超时/崩溃/输出截断 → 保留 finding + incomplete
- F06: exit 0 但空/畸形/陈旧/矛盾报告 → incomplete
- F07: 模块/方言/生成代码/配置继承 → 准确覆盖
- F08: 字符编码、特殊路径、空格、换行、非 UTF-8 → 身份可逆
- F09: 内容或原生配置同大小同 mtime 替换 → 缓存失效
- F10: 规则/工具/漏洞库更换 → 重新计算
