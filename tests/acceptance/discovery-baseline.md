# C03 detect 当前验收边界

`codeguard detect [path] [--format human|json]` 已接入只读观察端口。当前 `0.2.0` 报告包含语言候选的源码路径、清单路径、多构建根候选、`package.json` 的字面声明版本及清单 SHA-256、Java 标准目录的源集候选，以及 Maven POM 的检查器配置状态；被阻塞的路径、观察完整性和静态未知条件独立保留。`codeguard/` 内的源码照常参与发现。观察不会运行 Maven、P3C、wrapper 或项目脚本，也不会创建画像、任务或其它项目状态。

已执行的验收包括：真实 CLI 对临时 Java/Maven 项目返回 JSON 和 exit 0，项目目录内容不变；根路径不存在返回 exit 3 及部分报告；非法格式在观察前返回 exit 2；注入目录读取失败后，先前发现的清单和源码证据仍保留。`package.json` 的有效版本被读取，畸形 JSON 不产生虚假版本；项目 scripts 未执行。Unix 有界读取拒绝符号链接与超限文件。工作区单元与集成测试、严格 Clippy、OpenSpec 严格验证均通过。

当前边界：POM 只解析直接质量插件配置，其他清单内容与声明版本尚未解析；源集仅覆盖 Java 标准目录候选，方言和模块依赖未识别；构建模型在报告中保持 `build_model_not_evaluated`。锁文件仅登记路径，内容保持 unknown。路径观察结果只能作为候选，不得作为原生检查器能力或质量门禁完成的证据。OpenSpec 5.7 的静态查询与失败语义已验收；动态解析和各语言完整画像仍在后续任务中。
