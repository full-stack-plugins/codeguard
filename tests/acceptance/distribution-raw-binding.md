# raw 制品内容与缓存锁定位关联

对应 OpenSpec 5.3，正式安装未完成。

清单 1.2 raw 绑定要求原锁入口精确为 <二进制摘要>.bin；即使来源引用摘要与锁匹配，错误路径也拒绝。旧 1.0/1.1 仍可观察，但 inspect_distribution_raw 返回缺少新版映射，不能猜测/重写锁。

inspect_distribution_raw 静态绑定同一原清单/锁与工具/平台，核对精确包长度及 128 KiB 分块摘要，共享期限/取消。RawDistribution 借用冻结输入，不复制内容；只读访问器保留二进制摘要、锁/清单原字节摘要和精确定位，不提供批准或门禁状态；Debug 只输出长度/摘要，避免制品内容转储。发布层仍重新核验字节。

新增契约最初因 API 缺失编译失败。4 项普通 raw 契约覆盖无复制、长度/内容/陈旧锁拒绝、旧映射拒绝、工具选择、预算/取消、错误定位（连同相符来源摘要）拒绝；真实临时缓存发布后原锁入口摘要和基础可执行位匹配。预览对已绑定新版 raw 引导 verify_source_then_raw_package，旧声明仍提示 bind_raw_cache_locator；内容核验 not_run，不读包/写缓存。错误定位固定原因纳入反馈 schema。
