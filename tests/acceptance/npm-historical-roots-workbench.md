# npm历史构建根的准备恢复

范围：Unix CLI默认check all。初始化画像0.3中的npm根，在物理构建目录仍存在、清单当前不可用时，恢复为准备范围。画像必须是有界普通物理文件，其摘要与本地工作区受管记录一致；递归重复字段、错误协议标记、越界路径及词法别名均拒绝。此摘要只证明本地记录一致，不是策略批准或覆盖权威。

历史根不沿用旧清单摘要，不启动原生命令，即使同次请求提供完整工具参数；只观察当前输入状态，清单摘要为空并同步稳定环境任务。当前发现的其它根仍可执行显式原工具。恢复清单后重新走当前发现，重复扫描及恢复不新增同一义务的任务。反馈明确历史来源未批准和恢复清单后重新发现、原工具复检的动作。

测试：npm_historical_roots_cli曾以双根期望暴露只剩一个根的RED；现在验证重复扫描、准备摘要为空、稳定任务、当前兄弟根运行工具而历史根不运行，以及摘要失配、同时改本地摘要的越界路径、a//路径别名、错误document_type、重复JSON字段的拒绝。拒绝历史批次时保留当前兄弟根与已有任务；不能凭项目自行改摘要扩展到非法路径。

当前格式检查及CLI/新增测试Clippy -D warnings通过。普通受影响回归和其它验收结果见本次OpenSpec verification记录；工具替身的调用轨迹证明调度边界，不证明真实漏洞覆盖。已有真实Node/npm用例的结果单独记录，不能以普通夹具代替。

限制：只读取当前0.3初始化画像；旧版画像不恢复范围。物理构建目录整体消失时报告历史范围未完成；没有生成新的逐根缺目录任务。画像刷新删去曾有根后的完整义务恢复、可信工具上下文、外部配置不可用状态、Windows、完整CVE覆盖、宿主Hook及正式关闭/门禁仍缺。7.3/7.5/9.7保持未完成，不能据本项归档整个change。

最终普通验收：61项不同普通集成用例通过（Java24、check all npm2、部分契约13、SARIF6、npm audit1、历史根1、输入状态1、坏清单1、缺锁1、父工作区1、task verify10）；17项显式原生用例在普通命令中忽略。独立执行的历史-only默认检查实际反馈通过Draft202012，两轮稳定任务且历史清单摘要null。OpenSpec严格校验、diff空白检查通过。真实npm回归单独记录。

原生补充：显式既有Node v24.18.0/npm11.16.0的check all回归实际通过（22.45秒）；不安装、不执行包脚本。普通命令忽略的其余16项原生用例本轮未执行。准备恢复和本地一致性不等于漏洞库覆盖或白名单批准，完整计划仍未完成。
