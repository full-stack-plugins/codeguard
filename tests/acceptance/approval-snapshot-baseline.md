# 批准快照绑定切片

`approval-snapshot:1.0` 以策略修订、最长期限和候选原始字节 SHA-256 固定批准集合。候选新增、更改批准引用、快照内容变化、重复条目、未知字段、到期及缺时钟均不能得到 `BoundToPinnedSnapshot`。目标测试 `approval_snapshot_contract` 先因模块缺失失败；实现后覆盖正反例及公开 schema。

当前绑定函数是纯比较器。它能比对调用方提供的 finding 身份，但不能判断该身份是否确实来自本次原生扫描，也不能判断预期摘要、时钟是否来自受保护边界；不会签发 `allow_with_exceptions`。正式放行必须再接可信宿主/CI、扫描前已批准基线、时钟、原生发现和交付门禁。项目自行计算一个新摘要仍可使比较器返回“绑定”，所以该值绝不能单独作为批准凭据。
