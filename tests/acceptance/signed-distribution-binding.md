# 发行签名与原始清单/锁绑定

对应 OpenSpec 5.3，正式安装未完成。

新增发行专属信任公钥/上下文、严格版本化载荷/封装、只读 BoundDistributionSource 及 verify_signed_distribution。Ed25519 消息为 codeguard.distribution.v1 + NUL + key_id + NUL + 原始 release_json 文本；不复用白名单域，不重新序列化被签原文。封装 16 KiB、载荷 8 KiB、清单 256 KiB、锁 128 KiB 上限。签名固定发行者、通道、平台、序号、时间和原始清单/锁摘要。

受保护宿主须独立提供公钥、密钥发行者/期限/撤销、预期范围、时钟、最低序号及最长有效期。校验后仍解析/绑定全部清单制品至同一锁，所选平台必须存在；只读返回结果不支持 Deserialize，不授予网络或安装/门禁权威。不新增签发 CLI、项目公钥选项或未批准 apply。

测试先因 API 缺失编译失败。8 个 Rust 契约测试覆盖合法原始字节绑定、发行者/通道/平台失配、序号回滚、未来/到期/超长寿命、撤销/错公钥/缺时钟、字节空白篡改、其它协议域签名、签名相符但坏清单/锁身份/平台、未知/重复字段、超大输入，以及独立宿主密钥发行者/期限和无效上下文。测试 seed 仅用于构造固定签名反例，不是发行信任锚。两个 JSON Schema 代表性结构正例及所有必填缺失/未知批准反例通过；schema 只证明结构，签名由 Rust 单独核验。

真实发行信任根、轮换/撤销及防回滚持久状态、隔离宿主来源、网络许可、最终时钟重核、下载到正式安装编排仍缺；项目可写公钥/JSON 不能升级为授权。未执行远端真实签发/发行源或宿主验收，未运行全 workspace，5.3 保持未完成。

最终验证：签名 8、清单 14、完整布局 5、raw 4、tools 预览 25，共 56 项通过；1 项真实 Ruff ignored 不计运行。两份 Schema 2 个结构正例/15 个缺字段或未知批准反例通过。CLI all-target Clippy -D warnings、格式检查、OpenSpec 严格校验和插件 diff 检查通过。
