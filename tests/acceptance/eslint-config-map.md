# ESLint 显式monorepo配置映射验收

目录入口新增 --config-map ABS_PATH，读取1.0协议的projects数组。每项明确root/config/cwd，路径相对当前目录检查根；`.`表示根目录，所有路径必须规范化并经物理归属核验。映射最多64KiB/128个上下文，拒绝重复字段、未知字段、重复项目根、跳转或链接。按目录组件选择最深匹配根，未命中保留原命令配置及cwd，不执行映射中的其它内容、不自证规则批准。单文件入口使用该选项返回用法错误。

目录反馈升级0.2.0，保留映射字节摘要、逐文件configuration_scope及显式选择来源；schema同时保留历史0.1类型。所有显式配置纳入原输入前后摘要核对，映射与当前源码/所选配置在子任务启动前再核对，变动保留已取得观察和未执行清单，不能边扫描边默默换选择。既有逐文件任务报告保留实际原配置/cwd，原工具复检仍按首次上下文核查。

选项缺失先RED（未知参数）。受控CLI实测packages/a与packages/ab边界、根`.`及最深项目选择，重复根、越界和approved未知字段启动前拒绝；映射在首个原生扫描中被改写，后续三文件不再执行，目录input_stable=false。这里的执行脚本是协议夹具，不冒充ESLint。

本机既有Node24.18.0/ESLint10.11.0真实公开CLI检查两个项目及各自配置源码，80.78秒通过：根启用no-debugger，子项目关闭同规则，根源码有发现、子源码无发现，规则未被错误强加。四文件均局部一致，配置选择范围分别保留。没有安装或升级，仍coverage_proven=false、delivery_decision=not_evaluated。

45项相关普通回归及最终根`.`补充用例通过；目标Clippy -D warnings和fmt通过。映射schema及当前公开目录反馈由受控CLI实际产物通过Draft202012校验，越界映射schema反例被拒绝。OpenSpec最终校验见verification。

当前只支持显式选择原调用上下文。完整自动配置归属、JS导入/插件闭包、TS parser/tsconfig、完整原生源集、依赖/CVE、批准required规则、聚合硬I/O预算、正式关闭重开和宿主门禁仍缺，7.3/9.7不勾选。
