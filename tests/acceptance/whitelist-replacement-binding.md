# 白名单替代候选的局部绑定验收

范围：`false-positive-decision` 1.1 候选与 `approval-snapshot` 1.1 的结构核对；不证明受保护策略发布或交付门禁。

替代候选必须提供不同于新 ID 的 `replaces_decision_id`。旧 1.0 候选不能夹带替代字段。快照必须在同一修订中撤销该旧 ID；普通绑定接口在缺少旧决策字节时返回未核验。专用绑定还核对旧 ID、同一稳定 finding、检查器、规则、类别与精确目标归属，不能把一个文件的误报裁定扩到另一个文件。旧决策仍可在快照列表中，但撤销优先，不能再命中。

前序快照绑定补充核对：旧决策须以原始字节摘要列在另一份已固定的前序快照中，旧决策声明的策略修订须一致且未被该快照撤销。缺前序 pin、错误 pin、改写旧决策字节、前序已撤销或新旧同策略修订都不能得到绑定结果。此处两个 pin 的可信来源和时间顺序仍由调用方的受保护边界承担；本地自算两个摘要不能生成授权。

多跳绑定按直接前驱到普通根候选逐跳核对，最多 32 跳；同一稳定 finding 与精确目标必须贯穿全链，子快照必须撤销其前驱。链截断、乱序、根后多余节点、ID 或策略修订重复形成的环、前序候选有效期超出对应快照上限都拒绝。历史候选的到期时刻是否覆盖当时批准事件、各策略修订的真实时间顺序仍依赖受保护发布记录。

目标测试：`cargo test -p codeguard-cli --test false_positive_decision_contract --test approval_snapshot_contract --offline`。1.1 字段/返回类型、前序绑定和多跳接口的测试均先因缺实现编译失败；最后一次定向运行中快照契约 15 项通过。全工作区与静态检查结果见插件 OpenSpec `verification.md`。

未完成：旧决策字节与快照摘要的历史可信来源、各修订的真实先后与受保护发布、真实原工具复检引用、纠错提案 CLI、稳定任务事件及 CLI/MCP/Hook/SARIF 门禁。任何本地构造的摘要和批准文字都不能使例外生效。
