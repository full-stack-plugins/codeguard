# npm 锁文件节点关联验收（2026-09-27）

Rust `NpmLockedNode` 从有界、拒绝重复字段的 npm v3 锁文件解析普通安装节点，保留完整解析版本、精确安装位置与包名。原生审计节点按位置逐一核对名称，完整节点数量必须与原生 dependency total 一致。不同位置的同名包不合并版本。范围不是解析版本，npm source ID 不是 CVE。

两项契约测试覆盖重复安装、scoped 包、名称错配、链接/别名、缺版本、路径越界、重复 JSON 字段及不支持版本。API 缺失先失败，再实现通过；原有五项 npm 审计契约同时通过。

此处是协议夹具验收，已用真实 npm 11.16.0 验证夹具非空锁文件的离线零发现与节点计数；该运行不验证数据库覆盖或真实漏洞正例。链接/workspace/别名、依赖边、直接性核对、范围求值、库新鲜度、完整制品身份、公开命令和稳定修复任务仍缺。该观察不授予漏洞确认、白名单批准或交付通过。
