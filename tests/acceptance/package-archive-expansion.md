# ZIP/tar.gz 内存展开与入口发布

对应 OpenSpec S05/5.3 局部基础；完整发行安装未完成。本文保留首轮 11 项验收记录；后续 GNU/PAX 能力以 [扩展验收](tar-extension-verification.md) 为准。

runtime 新增 ArchiveUnpackRequest、UnpackedFile 及 unpack_package_archive；包字节上限 128 MiB，非零包/入口 SHA-256、明确入口和共享截止时间/取消。先核对包摘要，再向内存展开；不调用库的文件系统解包接口。返回按相对路径排序的冻结普通文件，不赋予批准、完整 bundle 或准备状态。

核验所有成员而非仅入口：规范 UTF-8 相对路径，拒绝控制字符、点段、回退段、绝对/Windows 歧义路径与保留名称；拒绝同名/大小写碰撞、祖先文件及文件目录冲突。至多 10000 成员，文件总量最多 512 MiB 且不得超过请求预算；tar 容器另最多给头和填充 16 MiB，采用有界逐段读、完整 gzip CRC/尾部核验并拒绝附加成员和 tar 非零隐藏尾部。ZIP 支持 stored/deflate，拒绝加密及其它算法/特殊类型；普通文件完整读取核验 CRC。请求或包损坏、缺入口/错摘要、取消/期限均无局部成功。

首轮 tar 实现只支持普通文件/目录；GNU/PAX/sparse/链接/设备等明确拒绝，不声称这些发行包已经支持。内存 tar 容器和冻结文件可能同时存在，512 MiB 文件预算不是进程总内存上限；正式资源调度仍待接线。未来落盘仍需再次处理实际文件系统归一化、归属与权限，不能以本次路径检查代替受管发布。

固定 tar 0.4.46、zip 6.0.0、flate2 1.1.10；关闭默认扩展和原生压缩后端，只在 runtime 普通依赖接入。参考 [tar 文档](https://docs.rs/tar/0.4.46/tar/)、[zip 版本/功能定义](https://docs.rs/crate/zip/6.0.0/source/Cargo.toml)；本地清单声明 MSRV 分别 1.63、1.83、1.67，当前工具链编译验证不等于实际 Rust 1.85 验收。Rust 包依赖正常 fetch，不安装或运行原生检查工具。

三项初始测试因 API 缺失失败；实施并补充后 11 项归档测试通过。涵盖两种格式、危险次要成员、重复/大小写/目录冲突、链接设备、损坏 gzip/ZIP、附加 gzip 成员、tar 非零隐藏尾部、ZIP 尾随数据/SFX 前缀、取消/到期、包或入口错摘要、缺入口/超限及普通目录。两种格式均实际串联包流校验→内存展开→原有缓存发布，临时制品内容重新读取核对；无原生工具启动或发行批准。全平台归档、bundle 树重算、完整目录原子发布、CLI apply、可信下载/批准及宿主端到端尚缺，任务不勾选。

相关包流 9 项、缓存发布 10 项、crate 边界 5 项、清单 11 项和工具 CLI 23 项通过；加本轮最终归档 11 项共 69 项通过。缓存的 1 项原生工具用例本轮 ignored，不计入运行。全 workspace 未运行。
