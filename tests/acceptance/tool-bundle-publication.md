# 完整工具目录的原子发布基础

对应 OpenSpec S05/5.3，正式安装仍未完成。

macOS/Linux 的 publish_tool_bundle 在输入完整树与预期摘要匹配后，固定缓存目录 FD，核对所有权/可写权限，独占创建私有目录。目录与文件均为 0700；逐组件 openat + O_NOFOLLOW，文件独占创建、分块写入并 fsync；空目录保留。发布前重新核对目录成员集合、所有普通文件内容、所有权/权限/单硬链接。目录遍历独立游标并区分 readdir 结束与失败，特殊文件以 O_NONBLOCK 打开后先拒绝类型。任何错误均为固定脱敏诊断。

发布使用 macOS renameatx_np(RENAME_EXCL) 或 Linux renameat2(RENAME_NOREPLACE)，不退回可覆盖 rename。最终目录为 <树摘要>.bundle，缓存目录同步后，再核对完整树才返回相对 InstalledBundle。并发方遇到已有目标只能核验后复用。已存在但坏内容、缺/额外成员或错误权限的目标保持原样。暂存清理只操作本次创建的规范成员，逐组件不跟随链接，并核对暂存名字仍对应原目录身份；被篡改而无法清理的私有暂存不作为安装成功。进程崩溃不保证清理；发布后同步、核验或预算失败也可能留下完整最终目录，重试必须重新核验。

初始 5 项契约因 API 缺失编译失败。实施后增加真实暂存期间取消用例，共 6 项目录发布测试：完整发布与空目录/0700/复用；篡改、额外目录、链接、硬链接、FIFO、根/子目录权限及缺空目录拒绝；错误摘要/形状、取消/期限及可写缓存不写入；链接/空目录碰撞不覆盖；两线程同时发布只有一个 newly_published；32 MiB 内容在实际暂存出现后取消并回收全部本次成员。此并发用例模拟独立调用，尚非跨进程或故障注入全集。

发行包串联契约另将固定 ZIP 经清单/锁/入口/子树关联后发布到真实临时缓存，再与既有 CLI hash_bundle_tree 精确交叉比较。未消费的外部启动器/兄弟目录仍留在关联结果，不宣称它们已经安装。

本机验收不证明 Linux/Windows 运行、不可绕过的同权限进程隔离、发行来源批准或原生工具可运行。缓存目的根到工具锁路径的正式映射、其它成员/运行时安装、可信下载、CLI apply/恢复及宿主验收仍未接通，5.3 不勾选。

本轮目录发布 6、投影 4、既有缓存 10、CLI 相关 57，共 77 项通过；1 项原生缓存测试 ignored 不计运行。最终 all-target Clippy -D warnings、cargo fmt --check、OpenSpec strict 和文档差异检查通过，未运行全 workspace。
