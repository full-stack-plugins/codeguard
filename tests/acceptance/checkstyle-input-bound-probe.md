# Checkstyle 输入绑定原生执行

对应 OpenSpec 6.3。Rust 显式请求固定源码、原配置、Java 入口、自包含 JAR 的四个不同物理路径及独立 SHA-256。缺字段、额外路径、路径别名、摘要不符在启动前拒绝；输入有界读取且共同截止/取消贯穿阶段。runtime 核对私有日志和新鲜 XML，再由原生版本/退出/文件范围判定解释，最后复核四个输入。输入变化时保留解析证据并返回 incomplete，不直接产生可用于关闭任务或白名单处置的活动 finding。

目标测试先因缺请求/服务 API 编译失败。模拟执行器测试覆盖局部诊断、配置中途变更、陈旧报告保留、摘要错误、取消/截止、缺失/额外/别名身份，模拟工具证据不算原生能力。另明确选择固定官方 Checkstyle 10.21.4 JAR 与 Java 21，经同一生产服务运行缺类型注释和补全文档两轮，原生诊断及零诊断均通过输入绑定。测试冻结摘要不是独立批准，临时目录均清理。

该服务尚未接入正式 CLI/project check。Java 入口摘要不证明完整 JDK 动态闭包；配置摘要不证明外部资源/自定义模块闭包、规则与原项目归属或独立网络隔离。同用户修改后恢复原字节的竞争不能由前后摘要排除。宿主来源、完整执行隔离/快照、配置/范围及报告来源权威、原生规则映射、其它 Java 注释变体、任务/白名单/门禁仍待完成，6.3 不勾选。
