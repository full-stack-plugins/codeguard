# 有界 GNU/PAX 扩展及有效文件边界

对应 S05/5.3 归档能力的后续实施；完整安装未完成。

新增 TarExtensionState，用完整扩展路径和局部 PAX size 描述下一普通文件/目录；消费后清空。GNU 路径最多 1025 字节（含唯一末尾 NUL），PAX 数据最多 64 KiB，按字节长度读取完整记录并全部消费，拒绝重复键、局部头重复、矛盾路径、非法记录/尾部或孤立状态。所有扩展计入 10000 成员上限和既有容器预算。

包和 gzip 校验后，以 tar 库的头字段解析核对校验和；实际数据边界按 PAX 生效 size 计算、checked arithmetic 和总量限制，不能沿旧头大小跳过。完整 GNU/PAX 路径优先于截断旧头，UTF-8 的旧头断裂不影响完整路径；最终生效路径仍拒绝穿越、保留名称、碰撞等。忽略的权限/时间/所有者/xattr 只作为已消费描述数据，不参与写入。支持无害全局描述，明确拒绝全局 path/size、linkpath、sparse 和字符集变换；不恢复链接、设备或其它特殊类型。

两项新正例在旧实现中因 type unsupported 失败；PAX size 覆盖旧头的正例又因 size mismatch 失败，随后修正为有效边界。最终归档测试 17 项通过，新增例覆盖长 GNU/局部 PAX 路径及不跨文件传播、全局描述、重复/危险/孤立扩展、截断/超长/大小溢出/穿越、合法 PAX size 覆盖及完整 UTF-8 覆盖截断旧头。size 覆盖样本与 tar 库标准迭代得到的路径/大小交叉比较，下一条 LICENSE 仍位于正确边界。既有两格式包流→内存展开→缓存发布回归仍通过。

完整全局 PAX/sparse/链接及额外压缩算法、bundle 树核验/目录发布、可信下载批准、正式 CLI apply 和宿主/全平台尚缺；未运行全 workspace，不勾选 5.3/5.6。所有成功仅说明冻结文件内容验证，不能推导准备或质量通过。
