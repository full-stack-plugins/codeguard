# lint all 历史非lint任务饥饿修正

对应2.1/9.x。公开RED复现：先通过build rust生成并同步真实本地构建阻塞，再用受控Cargo的Clippy输出生成本轮lint诊断；聚合报告保留finding但next为null。旧代码从全历史选中构建任务，再在末尾清空，导致当前Clippy修复指引丢失。

现在通过单次build_view事实校验，在允许的lint检查器集合内按既有优先级选择；历史非lint事实仍接受完整校验但不参与此类别选择。语法确认后备只读本轮原生/候选产生的任务ID。原单检查器入口与全队列next行为保持，末尾范围防御保留。公开回归断言Clippy简报可见，同时原构建事实仍存在；不通过删除任务逃逸。

默认四相关目标42通过/0失败/5条件忽略；WASM公开回归1通过，与默认同一验收行为不累计。实际包含Clippy简报的报告通过0.59schema。CLI全目标严格Clippy、crate分层、OpenSpec strict、diff通过。受控工具只证明选择与反馈行为，不证明规则准确率、可信门禁、宿主或完整矩阵。用户Erlang草稿未修改/执行。父任务保持开放。
