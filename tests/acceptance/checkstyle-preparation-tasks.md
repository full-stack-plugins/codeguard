显式 --workspace 的 Checkstyle 检查遇到前置/配置/报告阻塞时，生成 java.checkstyle.preparation 的本地准备观察，自动同步稳定 CG-B 任务。反馈升级 0.4，增加 new_blockers；0.3 schema 保留。任务不是源码 finding，规则依据、范围、步骤、复检、历史和关闭条件均明确要求恢复原工具条件，不关闭规则、不修改无关源码、不自动安装或批准白名单。

工作区 Checkstyle 准备槽位有稳定身份，诊断从缺参数变为缺配置、受影响源码变化时仍更新同一任务与观察，人工 Markdown 备注和勾选保留；任务状态仍 open。新报告核对工作区、有限结构、源码范围及内容；已消费历史仍按字节收据确认。取消、项目外目标、非 Java 源码不生成该准备任务。模块级前置归属和多个构建/JDK 选择的独立槽位仍待实现。

next 从最新摘要绑定的观察读取诊断与当前受影响路径，不从任务文本执行指令。更晚、已消费、同一源码范围且所有输入仍一致的原工具局部报告，只作为 same_scope_native_observed_unverified 线索：改为核对原选择、配置、批准及覆盖，避免继续恢复已可运行工具。更换配置、工具或源码后线索失效；不同文件、未消费报告、摘要失配不能恢复本范围。

该恢复线索不证明全 JDK 闭包、必需规则或原项目完整覆盖，不关闭任务、不签发交付许可。准备任务的正式 task verify、环境尝试到原义务的完整关联、宿主 Hook 和全项目恢复关闭仍缺；next 的复检指引当前使用显式 lint java 原工具参数。
