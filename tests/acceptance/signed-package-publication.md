# 签名发行包至受控缓存发布编排

对应 OpenSpec 5.3，正式 tools install 仍未完成。

新增 publish_signed_distribution_package，明确接收不可变签名/清单/锁/包、精确工具、已有缓存根、独立宿主密钥/上下文、可信时钟回调和共享预算/取消。仅本机平台及清单 1.2 定位；先签名/全部制品关联，再选择目标，raw 用精确长度/摘要/原定位，归档用完整布局/可选 bundle 核验，最终复用受控内容寻址发布层。没有网络或制品启动，不重写锁。只读收据仅说明原锁相对入口与本轮新发布/复用，不支持 Deserialize，不授予运行时/原生可运行性/质量或真实宿主批准。

时钟及签名分别在内容核验前、发布前、发布后重核；拒绝缺时钟和从固定上下文或本轮前次观察回退。取消和截止时间共享全部阶段。发布后失败可能留下完整制品但不返回成功，重试必须重新核验签名/包/目标/缓存；已有坏内容保留且拒绝覆盖。

新测试先因 API 缺失编译失败，随后 5 项契约通过：签名 raw 与 ZIP 完整布局发布到原锁定位、磁盘入口字节一致及再次复用；错误包、取消、发布前到期无写入；错误签名、无目标、外国平台和时钟回退均保持缓存为空；发布后时钟不可用返回失败，可信时钟恢复后重新验证复用；既有目标篡改不覆盖且原坏字节保留。所有发布在本机私有临时目录，测试 seed 不是真实发行信任根，不执行 tool 测试字节。

真实宿主信任库及撤销/序号持久来源、网络授权、下载到正式 CLI 安装接线、运行时与依赖闭包、恢复任务、其它平台和宿主仍缺。工具 install apply 未因这一底层 API 改为可自行批准；不得把用户可写公钥和时钟函数当作不可绕过宿主权威。未运行全 workspace，5.3 保持未完成。
