# 签名批准到处置字段的只读绑定（4.5/4.8 进行中）

DeliveryInput.policy_revision 是宿主独立冻结的当前修订，可缺省读取旧输入，但应用白名单时必须与处置修订完全一致。缺失、空值或另一修订均保留活动阻断与 Incomplete，不能从候选/处置文字倒推当前批准策略。普通无白名单结论保持兼容。

普通 bind_signed_false_positive_preview 先运行签名、严格快照与精确候选绑定；替代 bind_signed_false_positive_replacement_preview 必须先完成逐跳签名、撤销、替代与原生 Git 关系核验。未绑定候选不生成预览；输入候选最多 64 KiB，其它已有封装/快照预算仍生效。

BoundFalsePositiveDisposition 只读保留候选/快照字节摘要、已核对工作区/代码基线、签名 key ID/序号，以及与本轮观察一致的候选身份、决策引用、修订和有效期。内部构造不可从项目 JSON 反序列化；预览的 independent_approval_verified 始终 false，不提供授权方法或 CLI 自批入口。宿主仍必须认证公钥、策略/时钟及原生来源，签名成功不能替代这些步骤。

绑定时刻使用已核对当前上下文，当前预览 expires_at 取当前候选、当前已验签批准及当前密钥有效期的最小值。历史批准只在其受保护历史时刻核验，不将历史过期时间套到当前合法替代项。候选/观察漂移、篡改原始字节、签名到期/撤销、缺历史链、Git 无关或输入超限都不能获得绑定预览。

两个 RED 分别是最终门禁缺当前策略修订字段、签名处置入口缺失。处置三项验证元数据固定、双期限取最小、漂移/篡改/过期/撤销/超限，以及不自动授权；在合成模型中显式模拟独立来源审核后，再验证签名到期与策略更换仍阻断，该模拟不属于产品批准接口。真实 Git 签名链用例补充正常预览、历史今天已过期而当前仍有效、普通入口不能处理替代、Git 无关拒绝。
